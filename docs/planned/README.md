## Statusy

- **Szkic:** pomysł wymaga opisania lub doprecyzowania.
- **Do uzgodnienia:** opis jest gotowy do omówienia; pozostają decyzje.
- **Gotowe do realizacji:** zakres i kryteria akceptacji zostały zatwierdzone.
- **W realizacji:** trwają prace.
- **Wdrożone:** funkcja jest dostępna, a aktualna dokumentacja została uzupełniona.
- **Odłożone:** realizacja została świadomie wstrzymana.

Zacznij od problemu i oczekiwanego zachowania. Szczegóły techniczne można uzupełnić podczas omawiania pomysłu. Do kolejnych opisów użyj [szablonu](TEMPLATE.md). Opisy wdrożonych funkcjonalności zachowuj tutaj jako historię decyzji.
